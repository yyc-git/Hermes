# node_modules 体积诊断与瘦身(GTS-Play,2026-08-17 实测)

> 背景:兄弟反馈 node_modules 7GB → yarn install 慢 → worktree 建立慢。
> 关键结论:**7GB 不是 mods 的锅**(316 个 mods 嵌套 node_modules 仅 19MB)。

## 快速诊断(禁止 PowerShell 递归遍历)

PowerShell `Get-ChildItem -Recurse | Measure-Object` 在 7GB node_modules 上 >120s 超时。
用 **node 脚本**统计(秒级):

```powershell
# 根 node_modules 顶层大目录 TOP12
node -e "const fs=require('fs'),path=require('path');function dirSize(p){let s=0;try{for(const e of fs.readdirSync(p,{withFileTypes:true})){const fp=path.join(p,e.name);if(e.isDirectory())s+=dirSize(fp);else s+=fs.statSync(fp).size}}catch{}return s}const root='D:/Github/GTS-Play/node_modules';const top=fs.readdirSync(root,{withFileTypes:true}).filter(e=>e.isDirectory()).map(e=>({n:e.name,s:dirSize(path.join(root,e.name))}));top.sort((a,b)=>b.s-a.s);console.log('TOTAL:',top.reduce((a,b)=>a+b.s,0)/1e9,'GB');top.slice(0,12).forEach(t=>console.log((t.s/1e6).toFixed(0)+'MB',t.n));"

# 嵌套 node_modules(各 workspace 子包)总量
node -e "const fs=require('fs'),path=require('path');function dirSize(p){let s=0;try{for(const e of fs.readdirSync(p,{withFileTypes:true})){const fp=path.join(p,e.name);if(e.isDirectory())s+=dirSize(fp);else s+=fs.statSync(fp).size}}catch{}return s}const roots=['packages','demos','defaults','asset-lib','mods'];let total=0;const rows=[];for(const r of roots){const base='D:/Github/GTS-Play/'+r;if(!fs.existsSync(base))continue;for(const sub of fs.readdirSync(base,{withFileTypes:true})){const nm=path.join(base,sub.name,'node_modules');if(fs.existsSync(nm)){const s=dirSize(nm);total+=s;rows.push({p:r+'/'+sub.name,mb:Math.round(s/1e6)})}}}rows.sort((a,b)=>b.mb-a.mb);console.log('nested total:',(total/1e9).toFixed(2),'GB across',rows.length);rows.slice(0,15).forEach(r=>console.log(r.mb+'MB',r.p));"
```

## 7GB 构成实测表

| 位置 | 大小 | 处理 |
|------|------|------|
| `packages/frontend-multiplayer/node_modules/.cache` | 2.23 GB | **webpack 缓存,可安全删,自动重建** |
| 根 node_modules `.xxx-xxxxx` 残留(297个) | ~598 MB | yarn 1 临时拷贝残留,可删(被进程占用删不掉的留着无妨) |
| `file:` 外部依赖 | ~710 MB | vmd-physics-bake(310)+pmx-reduce-face(238)+bone-converter(161),`file:../../../X` 整体拷贝进 node_modules |
| rescript/bs-platform 系 | ~500 MB | rescript 10/12 双版本 + 重复残留(.xxx 和本体并存) |
| tsrpc 工具链 | ~227 MB | tsrpc-cli + .tsrpc-cli 残留 + tsbuffer-proto-generator |
| mods 源码(非依赖) | 487 MB | mmd-character-extend 一个就 425MB(模型资源) |
| **316 个 mods 嵌套 node_modules** | **仅 19 MB** | 兄弟误判大头,实际最小 |

## 第一刀:清理命令(零风险,立省 ~2.8GB)

```powershell
# webpack 缓存(删了下次编译自动重建)
Remove-Item 'D:\Github\GTS-Play\packages\frontend-multiplayer\node_modules\.cache' -Recurse -Force

# yarn 1 临时残留目录(^\..+-\w{6,}$ 模式)
Get-ChildItem 'D:\Github\GTS-Play\node_modules' -Directory |
  Where-Object Name -match '^\..+-\w{6,}$' |
  ForEach-Object { Remove-Item $_.FullName -Recurse -Force -ErrorAction Continue }
```

> 剩余删不掉的(被 node 进程占用):留着无妨,不参与解析。

## install 慢根因(诊断结论)

1. **316 个 mods workspace**:yarn 1 对每个 workspace 逐个解析、链接(mods 依赖都是内部小包 block/immutable/most/type-api)
2. **`file:` 依赖整体拷贝**:三个外部项目 ~710MB 每次 install 重新拷贝
3. **worktree 慢根因**:yarn.lock 在 .gitignore → 新 worktree 无 lock → 全量解析被 npmmirror 限流(2026-08-16 实锤)。解法:junction 共享(见 gts-worktree SKILL.md)或先复制 yarn.lock 再 install
4. **大依赖**:three 0.159.0(resolutions 锁定)、rescript
