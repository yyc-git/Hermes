# gts-conversation-end — 结束对话

> 触发词：`结束对话` / `结束` / `收工` / `完事`。
>
> 作用：清理现场（服务/定时器/未保存改动）+ 给总结 + 收尾，不再消耗 token。

---

## 流程

### Step 1：检查 + 清理现场

逐项检查：

| 检查项 | 动作 |
|--------|------|
| 服务（room/match/webpack） | 检查是否还在跑，如果在跑 → 问兄弟「要停吗？」 |
| Cron 定时器 | 检查当前 cron job 列表 |
| 未保存的改动 | `git status` 检查有无未 commit 改动 |
| 未保存的记忆 | 当前会话有无需要记住的重要信息 → 写入 memory/ |
| 残留进程 | 检查 Playwright 等可能残留的进程 |

### Step 2：给出总结（对话中）

直接在对话中输出总结，不发飞书：

```
🔚 对话结束
📋 服务：room-service <状态> | match-service <状态> | webpack <状态>
⏰ 定时器：<N> 个
💾 记忆保存：✅
💬 未提交改动：有/无
🧹 已清理：<清理项>
```

### Step 3：收尾

- 设置 Goal 为 complete
- 回复最后一条消息后不再主动发起任何操作
- 兄弟可以手动关闭 WebChat 页面，彻底不花 token

---

## 执行纪律

1. 不主动停服务——先问兄弟要不要停
2. 不发飞书通知——总结直接写在对话里
3. 记忆必须保存——不能丢掉当前会话的重要信息
