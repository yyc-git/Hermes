# 微信发送信息 Skill

> 触发词：兄弟说「发微信」「发给编辑」「发给余老师」「发消息给 XX」「加入发送微信信息的skill」
> 原则：**发送前必须问清内容 + 接收人，生成文案和步骤，等兄弟确认后才发**。正式商务消息（尤其发给编辑）禁止 bot 擅自发出。
> 默认接收人：**余老师**（编辑佘战文，成都艾瑞达文化传播有限公司，微信联系人「05.9」）

## 前置：机器人能力检查（1 次，30 秒）

判断能否用 openclaw-weixin 机器人主动推送，还是必须兄弟手动发：

```powershell
# ① 机器人是否运行
openclaw channels status --probe   # 找 "openclaw-weixin ... enabled, configured, running"

# ② 目标用户是否与机器人对话过（context_token 前提）
Get-Content "C:\Users\Administrator\.openclaw\openclaw-weixin\accounts\*.context-tokens.json"
# 有目标用户的 @im.wechat ID = 可主动推送；只有兄弟自己 = 不可推送给其他人
```

### 🔴 关键限制（2026-08-11 实测）

- 本机 openclaw-weixin 是**腾讯 iLink 独立 bot**（`97705a3c2e97@im.bot`），兄弟微信只用于扫码授权，**不是用兄弟个人微信号发消息**
- **主动推送前提**：目标用户必须**近期与机器人有过一次对话**（才有 context_token），否则消息无法送达/不实时提醒。实测 context-tokens.json 只有兄弟本人（o9cq802rdAZ4ZDRYiOOWymElobEg@im.wechat）
- 发文件（docx 等）需 wxclawbot-send / weixin-sender 技能，**本机未安装**；weixin-send 仅支持纯文本
- 结论：**发给编辑/外部联系人 = 兄弟手动发**（最正式）；机器人只能发给「跟它对话过的用户」

## 流程

### Step 1: 问清发送内容 + 接收人

- 默认接收人：余老师（编辑）。兄弟说「发给编辑/余老师」不用再问接收人，直接用
- 必须问（若兄弟没说）：
  1. **发送什么内容**？——文字消息？文件？文件路径？
  2. **接收人是谁**？——默认余老师；其它人问全名/昵称

### Step 2: 生成文案 + 发送步骤

**文案格式**（正式商务消息模板）：

```
[称呼]您好，[事情背景一句话]。

1. [要点一]
2. [要点二]
3. [要点三]

[收尾：请对方确认/回复]。
```

- 文字规范：口语化适度、不啰嗦、重点编号列出；涉及文件先说文件内容再给路径
- 涉及书名/方案变更时，文案里**必须写明变更理由**（如「书名定位到游戏领域后，全书案例可以聚焦游戏开发」）

**发送步骤**（机器人不可用时的标准路径）：
1. 给出文件绝对路径（若有附件）
2. 告诉兄弟：微信里把文件拖给「05.9」+ 粘贴文案（或先文案后文件）

### Step 3: 等兄弟确认

- **把完整文案 + 步骤贴给兄弟，等兄弟回复确认**（✅/发吧/OK）
- 兄弟确认前：**禁止发送任何消息**（无论手动还是机器人）
- 兄弟确认后：若是机器人可推送给目标（对话过的用户），用 `openclaw message send --channel openclaw-weixin --target "<用户ID>@im.wechat" --message "<文案>"`；否则提醒兄弟手动发

### Step 4: 发送后跟进

- 问兄弟是否已发出；编辑回复后记录要点（如对目录的反馈）到 daily log + 素材整理
- 若编辑有修改意见：更新对应文件 → 重新生成文案 → 再次等确认

## 注意事项

- 🔴 **发送前必等确认**：正式商务沟通（编辑/出版社）发错了影响信任，宁可多问一句
- 🔴 **默认接收人余老师**：wxid_ghy4vr5r5vzw22，昵称 05.9（微信聊天记录导出确认）
- 文件发送用兄弟手动微信：机器人无法给未对话用户发文件，也别让编辑加机器人（不正式）
- 文案中文化：书名用《》书名号；数字/编号用阿拉伯数字；不口语化（「咋」「呗」禁用）
- 内容涉及《VibeCodingBook》项目文件时，路径统一用 `D:\Github\VibeCodingBook\...`
- 本 skill 只负责「生成文案+步骤+确认」，**实际发出动作由兄弟执行**（除非目标是对话过的用户且兄弟明确要求 bot 发）
