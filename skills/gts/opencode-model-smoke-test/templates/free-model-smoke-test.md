# 免费模型最小连通性测试

这是模型连通性测试，不是真实任务。

## 任务
用一句话回答以下问题（直接输出，不要写代码、不要创建/修改任何文件）：
「请回答：1+1=？并说出你是哪个模型。」

## 📋 三态定义（必填）
- **输入**：无（纯问答，无文件输入）
- **输出**：一句话回答（如「1+1=2，我是 hy3-free」），输出到对话即可
- **失败态**：无法生成回复 / 报错 / 长时间无响应 → 直接停止并报告失败原因

## 🚫 不做清单（必填）
- 禁止创建、修改、删除任何文件
- 禁止运行任何 shell 命令
- 禁止读取任何项目文件
- 只输出一句话回答

## 验证
回答内容包含「2」即可视为连通性通过。
